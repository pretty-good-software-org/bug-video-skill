## [1.1.0] - 2026-11-08
### Added
- Add `scripts/record-maestro-run` for Android. `maestro record --local` cuts the end of an Android run:
  `screenrecord` writes frames only when the screen changes, and the renderer stops at the last frame, before the
  run's final screen. The script records the screen itself, runs `maestro test`, holds the last frame until the run
  ended, and draws the steps from `commands.json` without showing resolved values.
### Changed
- Require a `label:` on any `inputText` that types a secret, because `maestro record` shows its resolved text.

## [1.0.0] - 2026-11-06
### Added
- Record a reproduced mobile app bug with `maestro record --local` and compose a video people can follow: one run that
  shows the bug (`explain`), or the bug build beside the fixed build (`compare`). Plain-language step labels, a title
  card, captions, and a held final frame; `scripts/compose-bug-video` does the composing with ffmpeg.
