# Changelog

All notable changes to this project will be documented in this file.

## [1.1.4] - 2026-11-10
### Fixed
- Reject a `--font` or `--font-bold` path that does not exist with a `compose-bug-video:` error naming the option.
  `compose-bug-video` used to stop with a bare `cp` error instead.

## [1.1.3] - 2026-11-09
### Fixed
- Start `record-maestro-run` videos at the flow's first step. The recording began before Maestro started, so the first
  seconds showed whatever the device showed before the run, such as another app's signed-in screen. The skill also
  asks to leave the device on its home screen or on the app under test before each recording, and the script refuses
  to render a run without steps.

## [1.1.2] - 2026-11-09
### Fixed
- Call the scripts by their path, `scripts/compose-bug-video` and `scripts/record-maestro-run`, in the skill's
  examples, and say that paths are relative to the skill directory. The examples used bare script names, which are not
  on `PATH` once the skill is installed.

## [1.1.1] - 2026-11-08
### Fixed
- Find fonts on Linux in `record-maestro-run`: it falls back to DejaVu Sans when Arial is missing, as
  `compose-bug-video` does, and checks for fonts before recording, so a missing font no longer fails the run after
  Maestro has finished.

## [1.1.0] - 2026-11-08
### Added
- Add `scripts/record-maestro-run` for Android. `maestro record --local` cuts the end of an Android run:
  `screenrecord` writes frames only when the screen changes, and the renderer stops at the last frame, before the
  run's final screen. The script records the screen itself, runs `maestro test`, holds the last frame until the run
  ended, and draws the steps from `commands.json` without showing resolved values.
### Changed
- Require a `label:` on any `inputText` that types a secret, because `maestro record` shows its resolved text.

## [1.0.0] - 2026-11-06
### Added
- Record a reproduced mobile app bug with `maestro record --local` and compose a video people can follow: one run that
  shows the bug (`explain`), or the bug build beside the fixed build (`compare`). Plain-language step labels, a title
  card, captions, and a held final frame; `scripts/compose-bug-video` does the composing with ffmpeg.
